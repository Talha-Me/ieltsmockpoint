সার্ভারে প্রবেশের জন্য লোকাল পিসি থেকে SSH কমান্ডের মাধ্যমে লগইন করতে হয়। ধাপগুলো নিচে দেওয়া হলো:

ধাপ ১: প্রাইভেট কি ফোল্ডারে টার্মিনাল খুলুন
১. আপনার পিসির D:\personal websites\ieltsmockpoint ফোল্ডারে যান (যেখানে oracle_key.key ফাইলটি রাখা আছে)।
২. ফোল্ডারের ফাঁকা জায়গায় মাউসের ডান ক্লিক করে Open Git Bash here (অথবা PowerShell / Terminal) ওপেন করুন।

ধাপ ২: সার্ভারে SSH দিয়ে লগইন করুন
টার্মিনালে এই কমান্ডটি লিখে Enter চাপুন:

Bash
ssh -i oracle_key.key ubuntu@130.210.53.53
কানেক্ট হয়ে গেলে টার্মিনালে ubuntu@instance-...:~$ প্রম্পট দেখতে পাবেন। এর মানে আপনি সফলভাবে সার্ভারে প্রবেশ করেছেন।

ধাপ ৩: কোড আপডেট করুন
সার্ভারে লগইন করার পর সরাসরি এই কমান্ডগুলো চালিয়ে দিন:

Bash
cd ~/ieltsmockpoint
git pull origin main
npm install
pm2 restart ielts-mock
